# Made at Boston College

A responsive video showcase prototype with paired video cards, learner credits, search and category filters.

## Content

The names and projects are fictional demonstration content. The two silent eight-second concept clips are animated still images, not learner gameplay recordings.

Edit `app.js` to replace project details and video paths. Keep media under `assets/`.

## Preview

Run `python -m http.server 8765` in this folder and visit http://localhost:8765.

## Publishing

GitHub Pages publishes the root of the `main` branch. Push changes to `main` to update the site.
